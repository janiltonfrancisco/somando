Calculadora de Soma - Projeto Java com Interface Gráfica

Descrição do Projeto:

->Este é um aplicativo Java com interface gráfica que permite ao usuário somar dois números inteiros. O programa apresenta uma janela interativa onde o usuário pode inserir os valores, visualizar o resultado e realizar operações básicas como limpar os campos ou sair do aplicativo.

Funcionalidades:

->Soma de números inteiros: Insira dois números e obtenha o resultado da soma


Interface amigável: 

- Design limpo e intuitivo com botões claros

Operações adicionais:

- Limpar campos para nova operação

- Sair do aplicativo

Tecnologias Utilizadas:

1. Java Swing para a interface gráfica


2. Java AWT para manipulação de eventos


3. JDK (Java Development Kit) para compilação e execução


Como Executar o Projeto:

Pré-requisitos:

*Java JDK 8 ou superior instalado

*Ambiente de desenvolvimento Java (opcional)

Passos para Execução

Compilação:

bash

Copy

javac Principal.java

Execução:

bash

Copy

java Principal

Como Usar:

a. Digite o primeiro número no campo "Primeiro número"

b. Digite o segundo número no campo "Segundo número"

c. Clique no botão "Somar" para ver o resultado

d. Use "Limpar" para apagar todos os campos

e. Use "Sair" para fechar o aplicativo

Estrutura do Código:

Classe Principal: Contém toda a lógica da interface gráfica e manipulação de eventos

Métodos principais:

jButton1ActionPerformed: Realiza a soma dos números

jButton2ActionPerformed: Limpa os campos

jButton3ActionPerformed: Encerra o aplicativo
